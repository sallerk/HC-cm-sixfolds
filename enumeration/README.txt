enumeration/ -- CM types of abelian varieties of dimension g <= 6: enumeration, defect lattices and the
                Weil-character lattice test
=========================================================================================================

PURPOSE
For g = 1..6 the programs enumerate all pairs (G, Phi), where G runs over the W(B_g)-conjugacy classes of
subgroups of W(B_g) that contain the central involution rho, and Phi over the CM types up to the action of G.
For every pair they compute the rank of the Mumford-Tate group, the defect d and the defect lattice Lambda_U,
and they test whether Lambda_U is generated by characters of Weil classes (Lambda_W = Lambda_U).  Independent
pure-Python programs recompute the results from the stored group generators.

Model.  A CM algebra E = E_1 x ... x E_k of degree 2g with Galois closure L gives G = Gal(L/Q) acting on
X = Hom(E, C) = {0, ..., 2g-1}.  Complex conjugation acts as rho(i) = i+g mod 2g and is central in G, so G is a
subgroup of W(B_g) = centralizer of rho in S_2g.  The G-orbits on X are the factors E_i; a CM type Phi contains
one point of each pair {i, i+g}.  The enumeration contains every such (G, Phi) up to W(B_g)-conjugacy; not
every enumerated pair needs to be realised by CM fields.

DEFINITIONS AS IMPLEMENTED (cmenum.py; names of the JSON fields in brackets)
- Coordinates: X*(U_E) is identified with Z^g by chi -> (chi_i - chi_{i+g})_{i<g}, so [i] -> e_i and
  [i+g] -> -e_i.  Hodge cocharacters mu_h in {+1,-1}^g (h in G): +1 at i if i is in h.Phi, -1 if i+g is.
- dimMT [dimMT] = rank of the 0/1 indicator vectors of the sets h.Phi (h in G) in Z^{2g} = rank{mu_h} + 1.
- d [d] = g - rank{mu_h : h in G} = g + 1 - dimMT  (the defect).
- Lambda_U [LU] = {chi in Z^g : chi . mu_h = 0 for all h in G}: the characters of U_E that are trivial on the
  Hodge group; saturated of rank d; stored in Hermite normal form.
- primitive [primitive, one flag per orbit]: no non-trivial block system of G on the orbit O_i has
  Phi cap O_i as a union of blocks, i.e. the CM type of E_i is not induced from a proper CM subfield (the factor
  A_i is simple).
- isogenous pair [isog]: orbits O_i, O_j with a G-set isomorphism O_i -> O_j mapping Phi cap O_i onto Phi cap O_j.
- reduced [reduced]: all orbits primitive and no isogenous pair, i.e. (G, Phi) describes a product of pairwise
  non-isogenous simple CM abelian varieties.
- imaginary quadratic K [Ks]: K corresponds to a homomorphism G -> {+1,-1} with rho -> -1 (K = fixed field of
  its kernel).  K lies in E_i iff O_i has a G-invariant partition into two blocks interchanged by rho on which
  G acts through this sign; the block B_i containing min O_i (the embeddings of E_i that restrict to one
  embedding of K) is stored.  K is listed if it lies in at least one E_i.  t_i = 2|Phi cap B_i| - |B_i|.
- Lambda_W (strict) [adm, rankW, LW, index]: for K, a set J of orbits containing a K-block and signs e_i = +-1,
  B = union of the blocks B_i (e_i = +1) or rho(B_i) (e_i = -1), admissible iff balanced, i.e.
  |Phi cap B| = |B|/2 (equivalently sum e_i t_i = 0).  Its Weil character is w_B = sum_{x in B} [x].
  Lambda_W = Z-span of all such w_B (each simple factor used at most once).
- KEY TEST [passed]: Lambda_W = Lambda_U as lattices, i.e. rank Lambda_W = d and index 1.
- Weil characters with multiplicities [mult] (cmenum.mult_weil): sub-products of powers of A, encoded by
  c in Z^J; w = sum c_i w_{B_i}, dimension D = sum |c_i| g_i (g_i = |O_i|/2), balanced iff sum c_i t_i = 0.
  mult.Dmin = smallest D at which these w generate Lambda_U (searched up to D = 12; None if not reached).
- General CM fields K' (general_weil2.py): K' corresponds to a subgroup M of G not containing rho,
  [G:M] = [K':Q] <= 24; K' acts on A_i^m through the G-orbits on O_i x G/M.  genDmin [Dmin] = smallest dimension
  of a sub-product of powers of A at which the Weil characters for all such K' generate Lambda_U (D <= 12).
- G-orbit case: one record of enum_g{g}.json per pair (G, Phi) with Phi up to G (stored Phi = smallest
  representative of the G-orbit).
- W-class: a W(B_g)-conjugacy class of subgroups G containing rho; gid = its index in enum_g{g}.json (= the
  order of GAP's ConjugacyClassesSubgroups(W(B_g)) after filtering; gids depend on the GAP version).
- N-class [Nclass]: the orbit of Phi under the normalizer N_W(G), i.e. the pair (G, Phi) up to
  W(B_g)-conjugacy of pairs.  "W-classes of pairs" in the note are these N-classes.
- Explanation tier of a reduced pair with d >= 1 (final_tables.py): "strict" (KEY TEST passes); "IQmult<=6"
  (mult.Dmin <= 6); otherwise "needs D=genDmin".  Only Weil classes for CM fields acting on sub-products of
  powers of A, and the lattices generated by their characters, are considered; no other construction.

HOW TO RUN (from this folder; every script reads and writes relative to its own directory)
  Below, SAGE stands for
    docker run --rm --cpus=1 -v "$PWD":/work -w /work sagemath/sagemath:latest sage -python
  (--cpus=1 is optional; on Windows/Git Bash prefix MSYS_NO_PATHCONV=1 and use "$(pwd -W)" for "$PWD").
  Order of the full pipeline (each step reads the outputs of the earlier ones):
    SAGE run_enum.py g                    for g = 1, 2, 3, 4, 5, 6
    python fetch_apfv_data.py
    SAGE controls.py
    SAGE stage1.py
    SAGE general_weil2.py 4,5,6 12
    SAGE j11_check.py > j11_check_out.txt
    SAGE j15_check.py > j15_check_out.txt
  Pure Python:
    python verify_enum.py 1,2,3,4,5,6            (appends to verify_out.txt; delete it first for a fresh file)
    python verify_general.py > verify_general_out.txt
    python verify_controls.py > verify_controls_out.txt
    python verify_mutation_test.py > verify_mutation_test_out.txt
    python first_power.py > first_power_out.txt
    python summarize.py 1,2,3,4,5,6 summary_strict.txt
    python tiers.py 4,5,6 > tiers_out.txt
    python final_tables.py
    python used_blocks_check.py > used_blocks_check_out.txt
    cd cyclotomic_checks; python cyclo_examples.py > cyclo_examples.out;
                          python fermat_factor_search.py > fermat_factor_search.out; cd ..
    python open_families/fields_pari.py
    SAGE open_families/analyse_sage.py > open_families/log_analyse.txt
    python open_families/verify_indep.py
