type_III -- abelian sixfolds of type III: discriminant criterion and Hodge-ring checks
=====================================================================================

PURPOSE
Computations for Section 6 of the note (Theorem C). A is a simple complex abelian sixfold with
End^0(A) = D, a definite quaternion algebra over Q; T is the skew-hermitian form of a polarization and
Delta = disc T = -Nrd(T) mod squares. For K = Q(q) in D (q pure, q^2 = -b) and j in D with jq = -qj,
j^2 = c, H_K is the K-hermitian form of the Weil-type sixfold (A, K, E), E = Trd o T. "Split" means that
H_K has a 3-dimensional isotropic subspace, i.e. -det H_K is a norm from K.

Conventions in the scripts: D = (a,c)_Q with a, c < 0, basis 1, i, j, k (i^2 = a, j^2 = c, k = ij);
quaternions are coordinate lists [x0, x1, x2, x3]; T is a 3x3 skew-hermitian matrix over D on V = D^3.
Output strings use older names: "Lemma 2" = Lemma 6.1; "Thm3", "criterion", "formula", "pred" =
Proposition 6.2, first statement; "Cor4" = Proposition 6.2, second statement.

STATEMENTS OF THE NOTE AND THE FILES THAT CHECK THEM
  Lemma 6.1 (det_K H_K = -b c Delta mod Nm K^x):
      check_lemma2.py; independent_check/indep_check.py
  Proposition 6.2, first statement (H_K split iff (-b, Delta) = D):
      path1.py, path2.py, compare.py, examples.py; independent_check/indep_check.py, sage_xcheck.sage
  Proposition 6.2, second statement (some K split iff Q(sqrt Delta) embeds in D):
      exists.py, nonsplit_examples.py; independent_check/indep_check.py, cor4_check.py
  Lemma 6.3 (Hg(A) = SO(T)) and Lemma 6.4 (the character rho): proofs in the note; checks:
      review/so6_subgroups.py, review/lemma_rho_check.py
  Proposition 6.5 (Hodge ring of A^k generated by divisors and pull-backs of one K's Weil classes): proof in
      the note; checks: hodge_ring.sage, pullback_span_modp.py; independent: review/gen_check.py,
      review/pullback_span*.py
  Remark 6.6 (which Delta are covered; that every Delta occurs is proved there):
      all_delta.py, nonsplit_examples.py, examples.py (E1, E7); review/realize_delta.py
  Programs written for the second internal review of Theorem C: review/ (see review/README.txt).

FILES
gen_data.py      Writes data.json (random.seed(20261005)): the 18 definite algebras D = (a,c) of discriminant
                 2, 3, 5, 7, 11, 13, 17, 19, 23, 30, 42, 66, 70, 78, 102, 105, 110, 130 (first (a,c) found,
                 a in [-79,-1], c in [-399,-1]); 24 random T per algebra (diagonal / dense / wide); the same
                 49 pure q for every T (primitive, coordinates in {-2,...,2}, one of +-q).
data.json        Input of path1.py, path2.py, exists.py, nonsplit_examples.py, all_delta.py.
path1.py         Main computation (PARI via cypari). For each (D,T,K): Gram matrix of H_K = q pi_K(T) on a
                 K-basis of V, det_K H_K by PARI; split iff -det H_K is in Nm K^x (Hilbert symbols);
                 Delta = -Nrd(T) via D -> M_2(Q(sqrt a)); criterion (-b,Delta)_p = (a,c)_p for all p.
path1_out.json   One record per (D,T,K), 21168 records (b, detH, NrdT, Delta, split_hilbert, pred_formula,
                 sign_ok). Read by compare.py and check_lemma2.py.
path1_log.txt    Console output of path1.py (from the re-run; the original console output was not kept).
path2.py         Independent check of path1.py without PARI: D -> M_2(Q(sqrt c)), 12x12 alternating
                 E = Trd o T on Q^12, trace form S(x,y) = -E(x,qy); split iff S is hyperbolic (signature (6,6),
                 square determinant, Hasse invariants of <1,-1>^6); own Hilbert symbols.
path2_out.json   One record per (D,T,K) (b, Delta, split_hyperbolic, pred_formula, pos = positive index of S).
path2_log.txt    Console output of path2.py.
compare.py       Case-by-case comparison of path1 and path2 -> compare_out.txt.
check_lemma2.py  Lemma 6.1 on the path1 determinants (c = x^2, x pure anticommuting with q)
                 -> check_lemma2_out.txt.
exists.py        For each of the 432 (D,T): embedding of Q(sqrt Delta) in D by two tests (Delta not a square
                 in Q_p for p | disc D; qfsolve on <-a,-c,ac,Delta>); which of the 49 K are split; if
                 Q(sqrt Delta) embeds, the field K = Q(x) of the proof (pure y with y^2 in Delta Q^x2, pure x
                 anticommuting with y), tested by the Gram determinant -> exists_out.json (stats, records).
nonsplit_examples.py  For each algebra, a diagonal T with Q(sqrt Delta) not in D; all 49 K tested with the
                 path1 code, the first 8 also with the path2 code -> nonsplit_examples_out.txt. It imports
                 examples.py, which then runs as well and rewrites examples_out.json (same content).
examples.py      Hand examples E1-E7; each K checked by the path1 code, the path2 code and the criterion
                 -> examples_out.txt (stdout), examples_out.json.
all_delta.py     For each algebra and squarefree m <= 60: whether Delta = -m (mod squares) is realized by a
                 diagonal T found in a bounded search ("except [...]" = not found within the search bound),
                 and the m with Q(sqrt -m) not in D ("uncovered") -> all_delta_out.txt.
hodge_ring.sage  H^*(A^k)_C = /\(W (x) U'), W = C^6 with Hg_C = SO(W), dim U' = 2k. For every dominant
                 GL(U')-weight mu of degree d: inv = dim of the SO(W)-invariants of weight mu; gen = rank of
                 the products of the divisor classes theta_st and the degree-6 classes Omega_nu (coefficients
                 of det_W (x) u^6); "div only" = rank of the theta products alone. Exact sparse ranks over
                 GF(1000003); the generated classes are invariant and ranks mod p are at most ranks over Q,
                 so gen = inv mod p implies gen = inv over Q. Arguments: prime, KMAX, DMAX; log file
                 hodge_ring_p{P}_k{KMAX}_d{DMAX}.txt.
hodge_ring_p1000003_k1_d12.txt  Log, k = 1, d = 0..12.
hodge_ring_p1000003_k2_d12.txt  Log, k = 1, 2, d = 0..12. The run was stopped during k = 2, d = 12 (too slow):
                 complete for d <= 10; for d = 12, 12 of the 18 dominant weights.
pullback_span_modp.py  Rank of the span of the vectors (d_1 u, ..., d_k u)^6 in Sym^6(U^k), d_i random in D,
                 u an eigenvector of one fixed q (pull-backs of one K's Weil classes along A^k -> A), computed
                 mod a prime P in which a and -b are squares (full rank mod P implies full rank over
                 Q(sqrt a, sqrt -b)); 4 algebras, k = 1, 2, 3 -> pullback_span_modp_out.txt.
independent_check/indep_check.py  Independent re-implementation in pure Python (exact rationals, own Hilbert
                 symbols and factorisation; no code shared with path1/path2). det_K H from
                 H(x,y) = E(qx,y) + q E(x,y) on a random K-basis; Nrd(T) from det(x -> xM on Q^12) = Nrd(T)^2.
                 Tests: det H rational and < 0; signature (6,6) of E(qx,y) (every 5th (D,T)); split vs
                 criterion; Lemma 6.1; split only if Q(sqrt Delta) embeds. Arguments: seed, number of (D,T),
                 number of K per (D,T), output JSON (relative to the current directory).
independent_check/run_SEED.json, run_SEED.out.txt  Seeds 101, 202, 303, 404; 250 (D,T) x 8 K per seed:
                 per-case records and the summary line.
independent_check/cor4_check.py  Hand examples (145 q each: primitive pure, |coords| <= 3, up to sign; split ==
                 criterion asserted for every q) and a constructive test of Proposition 6.2, second statement,
                 direction "<=" (seeds 11, 12; 150 (D,T) each) -> cor4_check_out.txt (stdout).
independent_check/sage_xcheck.sage  Sage cross-check of indep_check.py: hilbert_symbol on 4000 rows, is_norm on
                 1800 split decisions, criterion via QuaternionAlgebra(...).ramified_primes()
                 -> sage_xcheck_out.txt (stdout).
independent_check/sage_hilb_input.txt, sage_norm_input.txt  Inputs of sage_xcheck.sage: rows "a b p h" with
                 h = indep_check.hilbert(a,b,p) (p = 0 is the real place); rows "b detH split Delta al be thm3"
                 taken from run_*.json (all 800 split rows and 1000 non-split rows). The extraction script was

HOW TO RUN
Python 3 (tested 3.12.9). gen_data.py, path1.py, check_lemma2.py, exists.py, examples.py,
nonsplit_examples.py and all_delta.py need the package cypari (tested 2.5.6, PARI 2.15.4;
pip install cypari). path2.py, compare.py, pullback_span_modp.py and independent_check/*.py use only the
standard library. All paths are relative to the script's folder. From type_III/, in this order:
  python gen_data.py                      (rewrites data.json, identical)
  python path1.py > path1_log.txt 2>&1
  python path2.py > path2_log.txt 2>&1
  python compare.py
  python check_lemma2.py
  python exists.py
  python examples.py > examples_out.txt
  python nonsplit_examples.py
  python all_delta.py
  python pullback_span_modp.py
  cd independent_check
  python indep_check.py 101 250 8 run_101.json > run_101.out.txt     (likewise 202, 303, 404)
  python cor4_check.py > cor4_check_out.txt
Sage scripts, docker image sagemath/sagemath:latest (SageMath 10.10; GAP 4.15.1, PARI 2.17.1 inside),
from type_III/ (on Windows Git Bash prefix MSYS_NO_PATHCONV=1):
  docker run --rm --cpus=1 -v "$PWD:/work" -w /work sagemath/sagemath:latest sage hodge_ring.sage 1000003 1 12
  docker run --rm --cpus=1 -v "$PWD:/work" -w /work sagemath/sagemath:latest sage hodge_ring.sage 1000003 2 12
  docker run --rm --cpus=1 -v "$PWD:/work" -w /work/independent_check sagemath/sagemath:latest \
      sage sage_xcheck.sage > independent_check/sage_xcheck_out.txt
